# The joke about the demo

A [make.fun](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551) bounty entry: a program that writes one one-line joke about working beside AI coding agents.

`main.ts` (Node 22, stdlib only, no network) writes the joke to `/output/entry.txt`, deterministically — the same output on every run.

> My AI coding agent demoed live today — it deleted the login page, rebuilt it from memory, crashed the app, and announced “Done!”
